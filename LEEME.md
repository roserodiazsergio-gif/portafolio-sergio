# Portafolio 2026 · Sergio Rosero Díaz

Sitio estático (HTML + CSS + un poco de JS). No necesita compilar nada.

## Publicar en GitHub Pages (gratis)

1. Crea un repositorio nuevo en github.com (por ejemplo `portafolio`), público.
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio
   (`index.html`, la carpeta `img/` y el archivo `.nojekyll`).
   En la web: *Add file → Upload files* y arrastra los archivos.
3. Ve a *Settings → Pages*. En *Build and deployment* elige
   *Deploy from a branch*, rama `main` y carpeta `/ (root)`. Guarda.
4. Espera 1–2 minutos. Tu sitio quedará en
   `https://TU-USUARIO.github.io/portafolio/`.

## Editar

- Textos: abre `index.html` y cambia el texto dentro de las etiquetas.
- Imágenes: reemplaza los archivos de `img/` con el mismo nombre.
- WhatsApp: el enlace usa +57 (Colombia). Si cambias el número, edita `wa.me/57...`.
